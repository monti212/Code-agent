Every command accepts `--help` for its full flag list, for example `ucode run --help`. Commands that talk to a server also accept `--standalone` to run a private server and `--server <url>` to target a specific one.

## run

`ucode run` sends a message and prints the reply without opening the interactive interface.

```bash
$ ucode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: U Code review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: ucode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ ucode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ ucode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ ucode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ ucode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ ucode run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ ucode run --help
```

## mini

`ucode mini` starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ ucode mini
```

Continue the last session.

```bash
$ ucode mini --continue
```

Start with a model and an initial prompt.

```bash
$ ucode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ ucode mini --help
```

## session

`ucode session` manages sessions.

```bash
$ ucode session list
```

Limit the list and print JSON.

```bash
$ ucode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ ucode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ ucode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ ucode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ ucode session import session.json
```

Import into a specific directory.

```bash
$ ucode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ ucode session --help
```

## auth

`ucode auth` manages AI providers and credentials.

```bash
$ ucode auth list
```

List them as JSON.

```bash
$ ucode auth list --format json
```

Log in to a provider.

```bash
$ ucode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ ucode auth login anthropic --method api-key
```

Log out of a saved account.

```bash
$ ucode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ ucode auth switch anthropic work
```

View all subcommands and flags.

```bash
$ ucode auth --help
```

## mcp

`ucode mcp` manages MCP (Model Context Protocol) servers.

```bash
$ ucode mcp list
```

Add a remote server.

```bash
$ ucode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ ucode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ ucode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ ucode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ ucode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ ucode mcp logout sentry
```

View all subcommands and flags.

```bash
$ ucode mcp --help
```

## plugin

`ucode plugin` manages plugins.

```bash
$ ucode plugin list
```

Include built-in server plugins.

```bash
$ ucode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ ucode plugin add @example/ucode-tui
```

Check package plugins for updates.

```bash
$ ucode plugin check
```

Update package plugins.

```bash
$ ucode plugin update
```

Remove a plugin from global configuration.

```bash
$ ucode plugin remove @example/ucode-tui
```

View all subcommands and flags.

```bash
$ ucode plugin --help
```

## serve

`ucode serve` starts the API and web server. See [Web](/cli/web).

```bash
$ ucode serve
```

Bind to all interfaces on a fixed port.

```bash
$ ucode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ ucode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ ucode serve --help
```

## service

`ucode service` manages the background server. See [Web](/cli/web).

```bash
$ ucode service start
```

Restart it.

```bash
$ ucode service restart
```

Show its status.

```bash
$ ucode service status
```

Stop it.

```bash
$ ucode service stop
```

Read a setting.

```bash
$ ucode service get hostname
```

Set a setting.

```bash
$ ucode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ ucode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ ucode service set env UCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ ucode service unset hostname
```

View all subcommands and flags.

```bash
$ ucode service --help
```

## api

`ucode api` makes a request to the running server.

```bash
$ ucode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ ucode api v2.session.list --param limit=10
```

Send a JSON body.

```bash
$ ucode api v2.session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ ucode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ ucode api --help
```

## upgrade

`ucode upgrade` upgrades U Code to the latest or a specific version. Alias: `update`.

<Callout type="warning">
  U Code does not publish releases yet, so there is nothing for `ucode upgrade` to install. Update a source checkout
  with `git pull` and `bun install` instead.
</Callout>

```bash
$ ucode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ ucode upgrade 1.18.15 --method bun
```

View all subcommands and flags.

```bash
$ ucode upgrade --help
```

## uninstall

`ucode uninstall` removes U Code and all related files.

```bash
$ ucode uninstall
```

Preview what would be removed.

```bash
$ ucode uninstall --dry-run
```

Keep configuration and session data.

```bash
$ ucode uninstall --keep-config --keep-data
```

View all subcommands and flags.

```bash
$ ucode uninstall --help
```
