These docs describe U Code and its APIs, configuration, and plugin system.

U Code installs and runs as `ucode`.

## Install

U Code does not publish packages or installers yet. Install it from source with [Bun](https://bun.sh):

<div data-install-code>
  <CodeBlock
    code={`$ git clone https://github.com/monti212/Code-agent
$ cd Code-agent
$ bun install
$ bun run dev`}
  />
</div>

`bun run dev` starts U Code from the checkout. To build a standalone `ucode` binary for your platform, run
`bun run --cwd packages/cli build --single`; the binary is written under `packages/cli/dist/`.

---

## Connect

U Code is built for Uhuru models. Create an API key at [uhuruai.co](https://uhuruai.co) under **Settings → API Keys**
(keys start with `uhuru_sk_`), then connect it:

```bash
ucode auth login
```

Choose **Uhuru AI** and paste your key, or set `UHURU_API_KEY` in your environment. See [Providers](/providers#uhuru-ai)
for the details.

U Code also supports many other LLM providers. Connect them [in the TUI](/cli/providers) with `/connect`, or see
[Providers](/providers) to configure custom providers.

## Customize

Make U Code your own by editing the [U Code config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). For terminal interface themes and keybindings, see [CLI
configuration](/cli/config).
