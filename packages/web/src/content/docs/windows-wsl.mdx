While U Code can run directly on Windows, we recommend using [Windows Subsystem for Linux (WSL)](https://learn.microsoft.com/en-us/windows/wsl/install) for the best experience. WSL provides a Linux environment that works seamlessly with U Code's features.

:::tip[Why WSL?]
WSL offers better file system performance, full terminal support, and compatibility with development tools that U Code relies on.
:::

---

## Setup

<Steps>

1. **Install WSL**

   If you haven't already, [install WSL](https://learn.microsoft.com/en-us/windows/wsl/install) using the official Microsoft guide.

2. **Install U Code in WSL**

   Once WSL is set up, open your WSL terminal and install U Code using one of the [installation methods](/docs/).

   ```bash
   git clone https://github.com/monti212/Code-agent
   cd Code-agent
   bun install
   bun run dev
   ```

3. **Use U Code from WSL**

   Navigate to your project directory (access Windows files via `/mnt/c/`, `/mnt/d/`, etc.) and run U Code.

   ```bash
   cd /mnt/c/Users/YourName/project
   ucode
   ```

</Steps>

## Desktop App + WSL Server

If you prefer using the U Code Desktop app but want to run the server in WSL:

1. **Start the server in WSL** with `--hostname 0.0.0.0` to allow external connections:

   ```bash
   ucode serve --hostname 0.0.0.0 --port 4096
   ```

2. **Connect the Desktop app** to `http://localhost:4096`

:::note
If `localhost` does not work in your setup, connect using the WSL IP address instead (from WSL: `hostname -I`) and use `http://<wsl-ip>:4096`.
:::

:::caution
When using `--hostname 0.0.0.0`, set `UCODE_SERVER_PASSWORD` to secure the server.
:::

```bash
UCODE_SERVER_PASSWORD=your-password ucode serve --hostname 0.0.0.0
```

## Web Client + WSL

For the best web experience on Windows:

1. **Run `ucode web` in the WSL terminal** rather than PowerShell:

   ```bash
   ucode web --hostname 0.0.0.0
   ```

2. **Access from your Windows browser** at `http://localhost:<port>` (U Code prints the URL)

Running `ucode web` from WSL ensures proper file system access and terminal integration while still being accessible from your Windows browser.

## Accessing Windows Files

WSL can access all your Windows files through the `/mnt/` directory:

- `C:` drive → `/mnt/c/`
- `D:` drive → `/mnt/d/`
- And so on...

Example:

```bash
cd /mnt/c/Users/YourName/Documents/project
ucode
```

:::tip
For the smoothest experience, consider cloning/copying your repo into the WSL filesystem (for example under `~/code/`) and running U Code there.
:::

---

## Tips

- Keep U Code running in WSL for projects stored on Windows drives - file access is seamless
- Use VS Code's [WSL extension](https://code.visualstudio.com/docs/remote/wsl) alongside U Code for an integrated development workflow
- Your U Code config and sessions are stored within the WSL environment at `~/.local/share/ucode/`
