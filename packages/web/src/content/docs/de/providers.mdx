U Code offers three providers. **Uhuru AI** is built in and is the default. **OpenAI** and **Anthropic** are available
when you bring your own API key for them.

| Provider | Provider ID | Credential |
| --- | --- | --- |
| Uhuru AI | `uhuru` | Uhuru API key, `UHURU_API_KEY` |
| OpenAI | `openai` | Your OpenAI API key, `OPENAI_API_KEY` |
| Anthropic | `anthropic` | Your Anthropic API key, `ANTHROPIC_API_KEY` |

To add a provider you need to:

1. Add the API key for the provider using the `/connect` command.
2. Optionally, configure the provider in your U Code config.

---

### Credentials

When you add a provider's API keys with the `/connect` command, they are stored
in `~/.local/share/ucode/auth.json`.

---

### Config

You can customize the providers through the `provider` section in your U Code
config.

---

#### Base URL

You can customize the base URL for any provider by setting the `baseURL` option. This is useful when using proxy services or custom endpoints.

```json title="ucode.json" {6}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "anthropic": {
      "options": {
        "baseURL": "https://api.anthropic.com/v1"
      }
    }
  }
}
```

---

#### Hiding models

You can hide specific models from the `/models` picker for a provider using the `blacklist` option. This is useful when a provider exposes models you don't want to use or select.

```json title="ucode.json" {6}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "anthropic": {
      "blacklist": ["claude-opus-4-20250514"]
    }
  }
}
```

The inverse `whitelist` option hides every model except the ones listed.

```json title="ucode.json" {6}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "anthropic": {
      "whitelist": ["claude-sonnet-4-20250514"]
    }
  }
}
```

Both options take an array of model IDs — the same IDs shown in the `/models` picker.

- `blacklist` removes the listed models from the picker.
- `whitelist` keeps only the listed models and hides the rest.
- You can combine them: `whitelist` narrows the set, then `blacklist` removes entries from it.

## Uhuru AI

Uhuru AI is U Code's default provider. Create an API key at [uhuruai.co](https://uhuruai.co) under
**Settings → API Keys**. Keys start with `uhuru_sk_`.

1. Run the `/connect` command in the TUI and select **Uhuru AI**.

   ```txt
   /connect
   ```

2. Paste your API key, or set `UHURU_API_KEY` in your environment instead.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

3. Run `/models` and select **U4.0** (`uhuru/uhuru-4.0`), or **U5.0** (`uhuru/uhuru-5.0`) for the hardest work.

   ```txt
   /models
   ```

To pin the endpoint yourself, configure it as a provider that speaks the standard chat-completions wire format:

```json title="ucode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "uhuru": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Uhuru AI",
      "options": {
        "baseURL": "https://ucloud.orionx.xyz/functions/v1/ucode-api/v1",
        "apiKey": "{env:UHURU_API_KEY}"
      },
      "models": {
        "uhuru-4.0": { "name": "U4.0" },
        "uhuru-5.0": { "name": "U5.0" }
      }
    }
  },
  "model": "uhuru/uhuru-4.0"
}
```

:::note
U4.0 and U5.0 can use U Code's tools, such as file edits and shell commands, and accept images. Access is opening in
stages: if a request is refused with "U Code is not enabled for your account yet", your account is not included yet.
:::

## Bring your own key

OpenAI and Anthropic models are listed under their own names. They run on your account with that provider and are
billed by that provider.

---

### OpenAI

1. Run the `/connect` command and select **OpenAI**.

   ```txt
   /connect
   ```

2. Select **Manually enter API Key** and paste your key, or set `OPENAI_API_KEY` in your environment instead. OpenAI
   also offers sign-in with a ChatGPT Plus or Pro account from the same menu.

   ```txt
   ┌ Select auth method
   │
   │ ChatGPT Plus/Pro
   │ Manually enter API Key
   └
   ```

3. Run `/models` and select an OpenAI model, for example `openai/gpt-5.2`.

   ```txt
   /models
   ```

---

### Anthropic

1. Run the `/connect` command and select **Anthropic**.

   ```txt
   /connect
   ```

2. Paste your Anthropic API key, or set `ANTHROPIC_API_KEY` in your environment instead.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

3. Run `/models` and select an Anthropic model, for example `anthropic/claude-sonnet-4-6`.

   ```txt
   /models
   ```

---

## Troubleshooting

If you are having trouble with configuring a provider, check the following:

1. **Check the auth setup**: Run `ucode auth list` to see if the credentials
   for the provider are added to your config.

2. **Check the environment**: If you rely on `UHURU_API_KEY`, `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`, make sure it is
   set in the environment that starts U Code.

3. **Check the base URL**: If you overrode `options.baseURL`, make sure it points at a working endpoint for that
   provider.
