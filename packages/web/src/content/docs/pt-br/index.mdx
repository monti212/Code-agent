[**U Code**](/) é um agente de codificação de IA de código aberto. Está disponível como uma interface baseada em terminal, aplicativo desktop ou extensão de IDE.

Vamos começar.

---

#### Pré-requisitos

Para usar o U Code no seu terminal, você precisará de:

1. Um emulador de terminal moderno como:
   - [WezTerm](https://wezterm.org), multiplataforma
   - [Alacritty](https://alacritty.org), multiplataforma
   - [Ghostty](https://ghostty.org), Linux e macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux e macOS

2. Chaves de API para os provedores de LLM que você deseja usar.

---

## Instalação

U Code does not publish packages or installers yet. Install it from source with [Bun](https://bun.sh):

```bash
git clone https://github.com/monti212/Code-agent
cd Code-agent
bun install
bun run dev
```

`bun run dev` starts U Code from the checkout. To build a standalone `ucode` binary for your platform, run
`bun run --cwd packages/cli build --single`; the binary is written under `packages/cli/dist/`.

#### Windows

:::tip[Recommended: Use WSL]
For the best experience on Windows, we recommend using [Windows Subsystem for Linux (WSL)](/docs/windows-wsl) and
installing U Code inside it.
:::

## Configuração

U Code is built for Uhuru models. If you already pay for OpenAI or Anthropic, you can also bring your own API key for them.

1. Create an API key at [uhuruai.co](https://uhuruai.co) under **Settings → API Keys**. Keys start with `uhuru_sk_`.

2. Run the `/connect` command in the TUI and select **Uhuru AI**.

   ```txt
   /connect
   ```

3. Paste your API key.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

You can also set `UHURU_API_KEY` in your environment instead. To use your own OpenAI or Anthropic key, select that
provider in `/connect`. [Learn more](/docs/providers#bring-your-own-key).

## Inicialização

Agora que você configurou um provedor, pode navegar até um projeto no qual deseja trabalhar.

```bash
cd /path/to/project
```

E execute o U Code.

```bash
ucode
```

Em seguida, inicialize o U Code para o projeto executando o seguinte comando.

```bash frame="none"
/init
```

Isso fará com que o U Code analise seu projeto e crie um arquivo `AGENTS.md` na raiz do projeto.

:::tip
Você deve commitar o arquivo `AGENTS.md` do seu projeto no Git.
:::

Isso ajuda o U Code a entender a estrutura do projeto e os padrões de codificação utilizados.

## Uso

Agora você está pronto para usar o U Code para trabalhar em seu projeto. Sinta-se à vontade para perguntar qualquer coisa!

Se você é novo no uso de um agente de codificação de IA, aqui estão alguns exemplos que podem ajudar.

---

### Fazendo perguntas

Você pode pedir ao U Code para explicar a base de código para você.

:::tip
Use a tecla `@` para buscar arquivos no projeto.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

Isso é útil se houver uma parte da base de código na qual você não trabalhou.

---

### Adicionando recursos

Você pode pedir ao U Code para adicionar novos recursos ao seu projeto. Embora primeiro recomendemos pedir para ele criar um plano.

1. **Criar um plano**

   O U Code tem um _Modo de Plano_ que desabilita sua capacidade de fazer alterações e, em vez disso, sugere _como_ implementará o recurso.

   Mude para ele usando a tecla **Tab**. Você verá um indicador para isso no canto inferior direito.

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   Agora vamos descrever o que queremos que ele faça.

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   Você quer dar ao U Code detalhes suficientes para entender o que você deseja. Ajuda conversar com ele como se você estivesse falando com um desenvolvedor júnior da sua equipe.

   :::tip
   Dê ao U Code bastante contexto e exemplos para ajudá-lo a entender o que você deseja.
   :::

2. **Iterar sobre o plano**

   Uma vez que ele lhe der um plano, você pode dar feedback ou adicionar mais detalhes.

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   Arraste e solte imagens no terminal para adicioná-las ao prompt.
   :::

   O U Code pode escanear qualquer imagem que você fornecer e adicioná-la ao prompt. Você pode fazer isso arrastando e soltando uma imagem no terminal.

3. **Construir o recurso**

   Uma vez que você se sinta confortável com o plano, volte para o _Modo de Construção_ pressionando a tecla **Tab** novamente.

   ```bash frame="none"
   <TAB>
   ```

   E peça para ele fazer as alterações.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### Fazendo alterações

Para alterações mais simples, você pode pedir ao U Code para construí-las diretamente sem precisar revisar o plano primeiro.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

Você quer ter certeza de fornecer uma boa quantidade de detalhes para que o U Code faça as alterações corretas.

---

### Desfazendo alterações

Vamos supor que você peça ao U Code para fazer algumas alterações.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

Mas você percebe que não era isso que você queria. Você **pode desfazer** as alterações usando o comando `/undo`.

```bash frame="none"
/undo
```

O U Code agora reverterá as alterações que você fez e mostrará sua mensagem original novamente.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

A partir daqui, você pode ajustar o prompt e pedir ao U Code para tentar novamente.

:::tip
Você pode executar `/undo` várias vezes para desfazer várias alterações.
:::

Ou você **pode refazer** as alterações usando o comando `/redo`.

```bash frame="none"
/redo
```
