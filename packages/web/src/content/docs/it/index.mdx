[**U Code**](/) e un agente di programmazione AI open source. E disponibile come interfaccia per terminale, app desktop o estensione per IDE.

Iniziamo.

---

#### Prerequisiti

Per usare U Code nel terminale, ti serve:

1. Un emulatore di terminale moderno, come:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux and macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux and macOS

2. Le chiavi API dei provider LLM che vuoi usare.

---

## Installa

U Code does not publish packages or installers yet. Install it from source with [Bun](https://bun.sh):

```bash
git clone https://github.com/monti212/Code-agent
cd Code-agent
bun install
bun run dev
```

`bun run dev` starts U Code from the checkout. To build a standalone `ucode` binary for your platform, run
`bun run --cwd packages/cli build --single`; the binary is written under `packages/cli/dist/`.

#### Windows

:::tip[Recommended: Use WSL]
For the best experience on Windows, we recommend using [Windows Subsystem for Linux (WSL)](/docs/windows-wsl) and
installing U Code inside it.
:::

## Configura

U Code is built for Uhuru models. If you already pay for OpenAI or Anthropic, you can also bring your own API key for them.

1. Create an API key at [uhuruai.co](https://uhuruai.co) under **Settings → API Keys**. Keys start with `uhuru_sk_`.

2. Run the `/connect` command in the TUI and select **Uhuru AI**.

   ```txt
   /connect
   ```

3. Paste your API key.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

You can also set `UHURU_API_KEY` in your environment instead. To use your own OpenAI or Anthropic key, select that
provider in `/connect`. [Learn more](/docs/providers#bring-your-own-key).

## Inizializza

Ora che hai configurato un provider, puoi spostarti in un progetto su cui vuoi lavorare.

```bash
cd /path/to/project
```

E avviare U Code.

```bash
ucode
```

Poi inizializza U Code per il progetto eseguendo il comando seguente.

```bash frame="none"
/init
```

Questo fara analizzare il progetto a U Code e creera un file `AGENTS.md` nella root del progetto.

:::tip
Dovresti committare il file `AGENTS.md` del progetto su Git.
:::

Questo aiuta U Code a capire la struttura del progetto e gli stili di codice usati.

## Utilizzo

Ora sei pronto a usare U Code sul tuo progetto. Sentiti libero di chiedergli qualsiasi cosa!

Se e la prima volta che usi un agente di programmazione AI, ecco alcuni esempi che possono aiutare.

---

### Fai domande

Puoi chiedere a U Code di spiegarti la codebase.

:::tip
Usa il tasto `@` per fare una ricerca fuzzy dei file nel progetto.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

Questo e utile se c'e una parte della codebase su cui non hai lavorato.

---

### Aggiungi funzionalità

Puoi chiedere a U Code di aggiungere nuove funzionalita al progetto. Pero ti consigliamo prima di chiedergli di creare un piano.

1. **Crea un piano**

   U Code ha una _Plan mode_ che disabilita la possibilita di fare modifiche e si limita a suggerire _come_ implementera la funzionalita.

   Passaci con il tasto **Tab**. Vedrai un indicatore nell'angolo in basso a destra.

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   Ora descriviamo cosa vogliamo che faccia.

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   Devi dare a U Code abbastanza dettagli per capire cosa vuoi. Aiuta parlargli come se stessi parlando a uno sviluppatore junior del tuo team.

   :::tip
   Dai a U Code molto contesto ed esempi per aiutarlo a capire cosa vuoi.
   :::

2. **Itera sul piano**

   Una volta che ti da un piano, puoi dargli feedback o aggiungere piu dettagli.

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   Trascina e rilascia le immagini nel terminale per aggiungerle al prompt.
   :::

   U Code puo analizzare le immagini che gli dai e aggiungerle al prompt. Puoi farlo trascinando e rilasciando un'immagine nel terminale.

3. **Implementa la funzionalita**

   Quando ti senti a tuo agio con il piano, torna in _Build mode_ premendo di nuovo il tasto **Tab**.

   ```bash frame="none"
   <TAB>
   ```

   E chiedigli di fare le modifiche.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### Apporta modifiche

Per modifiche piu semplici, puoi chiedere a U Code di implementarle direttamente senza dover prima rivedere un piano.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

Assicurati di fornire abbastanza dettagli, cosi U Code fa le modifiche giuste.

---

### Annulla modifiche

Mettiamo che tu chieda a U Code di fare alcune modifiche.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

Ma ti accorgi che non e quello che volevi. Puoi **annullare** le modifiche usando il comando `/undo`.

```bash frame="none"
/undo
```

U Code ora ripristina le modifiche e mostra di nuovo il tuo messaggio originale.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

Da qui puoi modificare il prompt e chiedere a U Code di riprovare.

:::tip
Puoi eseguire `/undo` piu volte per annullare piu modifiche.
:::

Oppure puoi **rifare** le modifiche usando il comando `/redo`.

```bash frame="none"
/redo
```
